# Backend Services Module

This directory contains the core backend services for the Telco Self-Care Platform.

## Structure
- Placeholder for backend services (Java/Spring Boot, Node.js, etc.)

## Available Commands
When this module has a package.json or pom.xml, root-level commands will execute them:
- `npm run lint:changed` - Lint changed modules (Node) / `mvn verify` (Java)
- `npm run test:changed` - Test changed modules
- `npm run build:changed` - Build changed modules
